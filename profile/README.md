# Infortts

### Open systems for useful work

Infortts builds open, composable software for intelligent workflows, developer tooling, knowledge systems, and practical automation.

We are solving a familiar problem: powerful tools are often fragmented, difficult to operate, and disconnected from the people and systems that need them. Infortts brings those pieces together through transparent projects, reusable components, and clear interfaces.

## Contributing

Infortts welcomes thoughtful contributions to its public repositories. Start with the repository README, open issues, and contribution guidance for the project you want to improve. Small documentation fixes, reproducible bug reports, tests, and focused pull requests are especially helpful.

Please do not submit secrets, private data, production credentials, or proprietary customer information.
